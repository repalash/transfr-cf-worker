transfr.one

Dead-simple, encrypted, super-fast, temporary file transfer/piping server, for your browser, code and terminal.

Drop a file anywhere on the page to upload it, click this box to browse, or paste a file or text with ⌘/Ctrl+V

Send file

The receiver needs it to open the file. It never leaves your browser.

The file is stored as it is. Anyone with the link can read it.

Upload a file

With curl

curl --upload-file ./file.txt {{ORIGIN}}

Once the file is uploaded, the endpoint will return the uploaded file URL.

{{ORIGIN}}/3f1c9b27d4e0-68d0f3a2/file.txt

With a custom filename

curl --upload-file ./file.txt {{ORIGIN}}/my-file.txt

Encryption with gpg

Files should be encrypted before upload to ensure privacy.

gpg -c -o- file.txt | curl {{ORIGIN}}/file.txt.pgp --data-binary @-

This will prompt for a passphrase before starting the upload, that can then be used to decrypt the file.

Once the file is uploaded, the endpoint will return the uploaded file URL which can then be downloaded and decrypted with gpg, or in the browser if the extension is .pgp

curl -L {{ORIGIN}}/3f1c9b27d4e0-68d0f3a2/file.txt.pgp | gpg --pinentry-mode loopback -d -o decrypted.txt

With javascript/typescript

fetch('{{ORIGIN}}/file.txt', {
    method: 'PUT',
    body: new File(['<data goes here>'], 'file.txt')
});

With python

import requests

with open('file.txt', 'rb') as f:
    data = f.read()

response = requests.put('{{ORIGIN}}/file.txt', data=data)

Download a file

The file can simply be downloaded with the link returned from the endpoint. The link can be opened in a web browser to download the file, alternatively:

With curl

curl -L {{ORIGIN}}/3f1c9b27d4e0-68d0f3a2/file.txt > file.txt

With javascript/typescript

fetch('{{ORIGIN}}/3f1c9b27d4e0-68d0f3a2/file.txt');

With python

import requests

response = requests.get('{{ORIGIN}}/3f1c9b27d4e0-68d0f3a2/file.txt')

Pipe: send live, store nothing

A sender and a receiver use the same address, in either order, and the data goes straight from one to the other. Nothing is stored. Make the name hard to guess: whoever connects first on it gets the data.

curl -T ./backup.tar {{ORIGIN}}/pipe/7f3a9c-backup
curl {{ORIGIN}}/pipe/7f3a9c-backup -o backup.tar

Stream: a file that keeps growing

Create a stream to get a read link to share and a write link to keep. Write to it for as long as you like; readers get what is there so far, or follow it live.

curl -X POST {{ORIGIN}}/stream/build.log
tail -f build.log | curl -T - "<write link>"
curl -N "<read link>?follow"

Readers can also ask for only what is new (?from=) or wait for it (?wait=), and the writer ends the stream with &close. The details are in the plain text guide.

Notes

  • Files are automatically deleted after {{TTL_LABEL}}.
  • Max file upload size is {{MAX_FILE_SIZE_LABEL}} ({{MAX_BUFFERED_FILE_SIZE_LABEL}} for a streamed upload without a Content-Length, like curl -T -, and for form uploads, like curl -F).
  • A stream holds up to {{STREAM_MAX_LABEL}} and is deleted {{STREAM_IDLE_LABEL}} after its last write. A pipe stores nothing.
  • Sending is limited to about 20 uploads a minute from one address (120 writes a minute to a stream).
  • Scripts and AI agents: the same instructions as plain text are at /llms.txt, and curl {{ORIGIN}} prints them. Send Accept: application/json with an upload to get the link, size and expiry as JSON.
  • This is a free service, please try not to abuse.
  • Powered by Cloudflare Workers. Check out the source code to host your own: https://github.com/repalash/transfr-cf-worker
